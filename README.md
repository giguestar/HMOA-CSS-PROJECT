## 🎯 주요 기능

### 1️⃣ 시공내역 통합 관리
- **한 번 입력으로 모든 데이터 자동 연동**
- 청구금액과 지급금액 통합 관리
  - 같은 금액일 때: 청구금액만 입력하면 자동 복사
  - 다를 때만 지급금액 별도 입력
- 부가작업(난간대, 방범창, 몰딩, 타일) 체크리스트
- 필수 제작 여부 자동 표시

### 2️⃣ 월간 스케줄 자동 생성 ✨ **NEW!**
- 시공내역 입력 즉시 캘린더에 자동 표시
- **업체별 색상 아이콘** (2글자 약어: LX, 케스, 청암, 한샘, 홈CC, 해모)
- **주소 3단계 분리 표기**: 앞2단어 / 아파트명 / 동호수
- **비거주 표시**: (비) 파랑색 라벨
- **동호수 조건부 주황색**: 난간대/방범창/롤망/루버 체크시
- **팀/장비 색상 구분**:
  - 시공팀 앞글자 (녹색)
  - 철거팀 앞글자 (빨간색)
  - 장비 주체 및 내용 (파란색)
  - 몰딩/타일 표시 (보라색)
- **토요일 AS 간단 표기** (현장명/메모)
- **평일/주말 칸 크기 차등** 적용
- 클릭하면 상세 수정 가능

### 3️⃣ 자동 정산 시스템
- **업체별 정산 주기 자동 계산**
  - LX, 한샘, 홈CC, 해모아: 매월 말일 정산
  - 케스코: 1~15일→20일, 16~30일→익월5일 정산
  - 청암: 21일/1일 정산 (입금 확인 건만)
- 청구/지급 금액 자동 집계
- 마진 자동 계산
- 엑셀 정산서 자동 출력 (개발 중)

### 4️⃣ 대시보드
- 이번 달 시공 건수, 매출 한눈에 확인
- 미정산 건수 실시간 모니터링
- 업체별/팀별 통계 자동 생성

## 💡 사용 방법

### 1. 시공내역 등록
1. 좌측 메뉴에서 "시공내역 등록" 클릭
2. 기본 정보 입력 (날짜, 발주업체, 시공팀, 주소 등)
3. 청구 금액 입력 (표준시공비, 보양비, 철거비, 장비비 등)
4. 지급 금액이 다를 경우에만 별도 입력
5. 부가작업 추가 (난간대, 방범창 등 필수 체크)
6. "등록하기" 클릭

### 2. 스케줄 확인
1. "월간 스케줄" 메뉴 클릭
2. 자동으로 생성된 캘린더 확인
3. 각 일자별 시공 내역이 색상별로 표시됨
4. 카드 클릭 시 수정 화면으로 이동

### 3. 정산 처리
1. "정산 관리" 메뉴 클릭
2. 업체 선택 및 기간 설정
3. "정산 계산" 클릭
4. 청구/지급 금액, 마진 자동 계산
5. "정산서 다운로드"로 엑셀 출력 (개발 중)

## 🔧 기술 스택

### Frontend
- **React 18**: UI 라이브러리
- **Vite**: 빌드 도구
- **TailwindCSS**: 스타일링
- **Axios**: HTTP 통신
- **React Router**: 라우팅

### Backend
- **Node.js**: 런타임
- **Express**: 웹 프레임워크
- **Better-SQLite3**: 데이터베이스
- **ExcelJS**: 엑셀 출력 (개발 중)

## 📊 데이터베이스 구조

### construction_records (시공내역)
- 기본 정보: 날짜, 업체, 고객명, 주소, 팀, 거주여부
- 청구 금액: 표준시공비, 보양비, 철거비, 장비비, 실측비
- 지급 금액: 외주공사비, 실정산금액
- 정산 상태 및 비고

### additional_works (부가작업)
- 작업 유형, 필수 여부, 비용, 메모

### company_settings (업체 설정)
- 업체명, 정산 유형, 색상 코드

### team_settings (팀 설정)
- 팀명, 팀 유형, 지급율
