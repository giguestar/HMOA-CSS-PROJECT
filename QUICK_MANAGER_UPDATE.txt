==============================================
  🚀 PowerShell 한 번에 업데이트 (추천)
==============================================

PowerShell 관리자 권한으로 실행 후 아래 명령어 복사/붙여넣기:

# 1단계: 프로젝트 폴더 이동
cd C:\HMOA-CSS-PROJECT

# 2단계: 서버 종료
Stop-Process -Name "node" -Force -ErrorAction SilentlyContinue

# 3단계: 최신 코드 다운로드
git pull origin genspark_ai_developer

# 4단계: 패키지 설치
npm install

# 5단계: 매니저 계정 생성
node migrate_users.js

# 6단계: 서버 실행
npm run dev

==============================================
  🔧 문제 해결
==============================================

❌ 포트 3000 사용 중 오류
  → taskkill /F /IM node.exe
  → npm run dev

❌ "Cannot find module 'bcryptjs'" 오류
  → npm install

❌ 로그인 화면이 안 보임
  → Ctrl+Shift+N (시크릿 모드)
  → Ctrl+F5 (강력 새로고침)
