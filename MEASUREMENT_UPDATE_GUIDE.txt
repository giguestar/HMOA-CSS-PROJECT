Step 1: 서버 중지
──────────────────────────────────────
  Ctrl + C


Step 2: 다운로드
──────────────────────────────────────
  https://github.com/giguestar/HMOA-CSS-PROJECT/archive/refs/heads/genspark_ai_developer.zip


Step 3: DB 마이그레이션 ⚠️ 필수!
──────────────────────────────────────
  node migrate_db.js

성공 메시지:
  ✅ needs_fabrication 컬럼 추가 성공
  ✅ frame_count 컬럼 추가 성공
  ⚠️ 마이그레이션 완료!


Step 4: 서버 재시작
──────────────────────────────────────
  npm run dev


Step 5: 시크릿 모드 테스트
──────────────────────────────────────
  시크릿 모드: Ctrl + Shift + N
  주소: http://localhost:3000

1. 실측 요청 등록
──────────────────────────────────────
  ① 로그인 (admin / admin1234)
  ② "📏 실측 관리" 메뉴 클릭
  ③ "+ 실측 요청 등록" 버튼
  ④ 정보 입력:
     - 대리점: LX/케스코/청암/한샘/홈CC/해모아
     - 고객명: 테스트 고객
     - 주소: 울산 남구
     - 상세주소: 신정푸르지오 202동 1501호
     - 실측 오더일: 오늘 날짜
     - 담당 매니저: 이상무/정호규/김남군
     - 실측 예정일: 내일
     - 실측 약속시간: 10:00
  ⑤ "등록하기" 클릭


2. 실측 달력 확인 ⭐
──────────────────────────────────────
  ① "📆 실측 달력" 메뉴 클릭
  ② 월별 캘린더에서 등록한 실측 확인
  ③ 매니저별 색상 확인:
     - 이상무: 파란색 🔵
     - 정호규: 녹색 🟢
     - 김남군: 주황색 🟠
  ④ 실측 카드 클릭 → 상세 정보 팝업
  ⑤ "수정하기" 버튼으로 수정 화면 이동


3. 실측→시공 자동 연동 테스트
──────────────────────────────────────
  ① 실측 목록에서 등록한 실측 수정
  ② "확정 시공일" 입력 (예: 7일 후)
  ③ "수정하기" 클릭
  ④ "📅 월간 스케줄" 메뉴로 이동
  ⑤ 확정한 시공일에 자동 등록 확인!


4. 6일 전 규칙 경고 테스트
──────────────────────────────────────
  ① 실측 수정 화면에서
  ② "실측 완료일": 오늘
  ③ "확정 시공일": 5일 후 (6일 미만!)
  ④ "수정하기" 클릭
  ⑤ ⚠️ 경고 팝업 확인:
     "⚠️ 경고: 시공일까지 5일 남았습니다.
      6일 전 규칙을 위반합니다.
      그래도 진행하시겠습니까?"


5. 비거주 아이콘 확인
──────────────────────────────────────
  ① "월간 스케줄" 메뉴
  ② 비거주 고객 등록 시
  ③ 파란 테두리 "비" 아이콘 표시 확인

문제 1: "Cannot find module" 에러
──────────────────────────────────────
  npm install


문제 2: 포트 3000 사용 중
──────────────────────────────────────
  # Windows
  netstat -ano | findstr :3000
  taskkill /PID [PID번호] /F

  # macOS/Linux
  lsof -ti:3000 | xargs kill -9


문제 3: DB 마이그레이션 실패
──────────────────────────────────────
  # DB 백업
  cp server/construction.db server/construction.backup.db
  
  # 다시 시도
  node migrate_db.js


문제 4: 실측 메뉴가 안 보임
──────────────────────────────────────
  ① 브라우저 캐시 삭제 (Ctrl+Shift+Delete)
  ② 시크릿 모드로 다시 접속
  ③ admin 계정으로 로그인 확인
